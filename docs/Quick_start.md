# Quick_start.md

## Purpose
Prevent V–Johnny merge in Cyberpunk 2077 Relic storyline.

## Prerequisites
- CET (Cyber Engine Tweaks) installed in game
- Redscript (if Reds script overrides are used)
- WolvenKit for deeper analysis

## Steps
1. Load test save: ManualSave-5 (pre-Heist, 29.10.2022)
2. Install CET script from src/cp2077-merge-bypass/
3. Run The Heist with mod active
4. Verify merge does not occur

## Save Caveat
Old saves (2022) may require game version compatibility steps.
